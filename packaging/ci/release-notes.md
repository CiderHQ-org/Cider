Quadra 0.37.p2 fixes the Grid look, where text could vanish, and the same faults in Monochrome. Nothing else changes from 0.37.p1.

- **Dropdown values stay whole:** a long subtitle could squeeze the chosen value of a dropdown to an ellipsis. Settings -> Quadra M2VK -> Accuracy showed "…" instead of "Fast" in the Grid and Monochrome looks. Every dropdown now keeps its value readable.
- **Disabled buttons are no longer dimmed twice:** newer libadwaita versions (1.10 was checked) fade disabled buttons with a filter, and the theme faded them by opacity as well, which left them at about a fifth of their strength. "Apply and restart Quadra" was nearly unreadable while disabled. Buttons, link buttons and switches are now dimmed once, and a disabled main button has a readable style of its own.
- Everything in the 0.37 and 0.37.p1 notes still applies: Roblox Studio in its own section, the move to QuadraHQ/Quadra, the Simplified Chinese translation and Studio's Vulkan layer in the distro packages.

Validation: every launcher page was scanned for labels that are hard to read or cut short in Grid at four window widths (1100, 900, 760 and 620 px) and in Monochrome and GNOME at 1100 px; none are left in Grid or Monochrome. The 432 unit tests and the 8 GTK UI tests pass, and a new UI check fails without the dropdown fix. Fractional scaling on a real Wayland desktop was not tried.

Fully close and reopen Quadra after updating. Studio is not in the Flatpak. OpenGL remains the default for the game; VR requires OpenGL or Vulkan/Zink. Native packages include the matching Metal host and framework. Install `.pkg.tar.zst` on Arch derivatives, `.deb` on Ubuntu 24.04+/Debian 13+, or the binary `.rpm` on current Fedora. Darling/CiderDarling downloads remain separate. Source archives, build recipes and `SHA256SUMS` are attached.
