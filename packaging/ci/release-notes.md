Quadra 0.37.p1 puts the Vulkan layer that Roblox Studio's Vulkan renderer needs into the distro packages. Nothing else changes from 0.37.

- **Studio's Vulkan renderer in the packages:** the 0.37 packages did not contain the layer that keeps Studio's swapchain alive under Wine, because the build containers had no Vulkan development headers and the optional layer was skipped. With the 0.37 packages, choosing **Vulkan** under Settings -> Studio -> Graphics showed that the fix was not built. The recipes now require the headers, and the release build fails if the layer is missing from a package. Installs from source get the layer when the Vulkan headers are installed; the other renderers never needed it.
- Everything in the 0.37 notes still applies: Roblox Studio in its own section, the move to QuadraHQ/Quadra and the Simplified Chinese translation.

Validation: the layer compiles in the Ubuntu 24.04, Fedora and Arch build images with the dependencies the release build installs, and was loaded by Studio's Vulkan renderer on a real NVIDIA GPU in 0.37 testing. The package contents are checked by the release build itself. The Nix package still builds without the layer.

Fully close and reopen Quadra after updating. Studio is not in the Flatpak. OpenGL remains the default for the game; VR requires OpenGL or Vulkan/Zink. Native packages include the matching Metal host and framework. Install `.pkg.tar.zst` on Arch derivatives, `.deb` on Ubuntu 24.04+/Debian 13+, or the binary `.rpm` on current Fedora. Darling/CiderDarling downloads remain separate. Source archives, build recipes and `SHA256SUMS` are attached.
