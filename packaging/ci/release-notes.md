Quadra 0.36 removes the roughly 18 second menu freeze after leaving a game and updates Quadra M2VK, with a settings tab, a startup self-test and better diagnostics.

- **Leaving a game:** Roblox's network loops (`RBX IoEvLoop`) slept up to 10 seconds per wait and were not woken for the work that follows a leave, so the menu stayed unusable for about 18 seconds. They now look at their queues every 100 milliseconds (`kevent_poll_ms`, on by default, `0` turns it off). On an RTX 3060 Ti with Zink on Wayland the game ran at full speed 2 seconds after a leave in 3 of 3 cycles against 18 seconds in 9 of 9 before, and Play worked 2.8 seconds after the first leave against 18.2 seconds. Idle CPU did not rise. This works around Darling's kqueue emulation; what the loops were not woken for is not identified yet.
- **Quadra M2VK:** memory priority and pageable device-local memory are enabled by default, there is a Quadra M2VK settings tab, the GPU path is proven before launch with an automatic one-time fallback to OpenGL, and the log names the GPU and driver, why a drawable acquisition timed out and large or slow buffer creations.
- **Bug reports:** `quadrahq --watch-stalls` records what the game's threads do while it hangs, and the hardware report adds the GPU and driver, session, desktop, Xwayland version, window backend and raw mouse setting.
- **Website:** the report form and guide moved to the VPS with validated archives and queued Discord delivery.

Validation: 320 Python tests and native helper checks in the isolated run the release workflow uses (all passed), a Mach-O kqueue fixture run in a disposable Darling prefix with the cap off and on, and automated join-and-leave cycles with the watcher recording. Only one experience and one setup (RTX 3060 Ti, NVIDIA 615.78, niri, Zink, VR on) were tried; AMD, Intel, X11 and long play were not.

The new GTX 1060 / Wayland / Zink / MangoHud exit and the RX 6800 loading crash remain undiagnosed: neither supplied log includes a fatal fault address or stack. The Renoir/Metal memory mitigation still needs gameplay confirmation on the affected laptop. This patch does not claim to fix those crashes.

Fully close and reopen Quadra after updating. OpenGL remains the default; VR requires OpenGL or Vulkan/Zink. Native packages include the matching Metal host and framework. Flatpak does not include the Metal bridge yet. Install `.pkg.tar.zst` on Arch derivatives, `.deb` on Ubuntu 24.04+/Debian 13+, or the binary `.rpm` on current Fedora. Darling/CiderDarling downloads remain separate. Source archives, build recipes and `SHA256SUMS` are attached.
