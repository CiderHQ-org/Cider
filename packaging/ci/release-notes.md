Quadra 0.35.p1 fixes setup channel selection and native Wayland copy/paste, improves shared GPU memory handling, and explains OverlayFS startup failures.

- **Roblox setup and updates:** setup, startup checks and ordinary manual checks use the public release channel. Saved rollout channels and old required-update logs cannot redirect installation to a restricted channel. The client's explicit required-update recovery can still install its validated deployment.
- **Wayland copy and paste:** fix the reproduced rich-text paste crash by transferring the plain text supported by the host clipboard. Preserve Unicode through legacy and UTF-8 string APIs, and avoid retaining stale RTF data after another application replaces the clipboard.
- **Integrated GPU memory:** Quadra M2VK refreshes graphics budgets during play, respects host/cgroup pressure, caps low-memory APUs at 512 MiB and scales larger APUs with RAM. Optional resident shader preloads use at most a quarter of the estimated graphics budget. This mitigates the reported Renoir memory exhaustion; gameplay confirmation on that laptop is still needed.
- **No window / exit code 1:** recognize Darling's `Cannot mount overlay: No such device` failure at the first warmup. Show module-loading, kernel-reboot and custom-kernel recovery instructions before attempting to launch Roblox. The affected machine still needs working OverlayFS support.
- **Launcher and NixOS:** show the selected Darling runtime's live running/stopped status, simplify the dashboard and add NixOS packaging with a bundled CiderDarling runtime and NixOS module.

Validation includes 269 Python tests and native helper checks, real GTK update flows, real Darling AppKit clipboard/input regressions, Rust memory/preload tests, a real Metal device budget-refresh regression, and exact 1×/4× MSAA readback on software Vulkan and NVIDIA. The separate RX 6800 / regular-Darling OpenGL loading-crash report remains undiagnosed because its log contains no fatal signal or crash stack; this patch does not claim to fix it.

Fully close and reopen Quadra after updating. OpenGL remains the default; VR requires OpenGL or Vulkan/Zink. Native packages include the matching Metal host and framework. Flatpak does not include the Metal bridge yet. Install `.pkg.tar.zst` on Arch derivatives, `.deb` on Ubuntu 24.04+/Debian 13+, or the binary `.rpm` on current Fedora. Darling/CiderDarling downloads remain separate. Source archives, build recipes and `SHA256SUMS` are attached.
