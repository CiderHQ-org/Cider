Quadra 0.37 gives Roblox Studio a section of its own, moves the project to QuadraHQ/Quadra and adds a Simplified Chinese translation.

- **Roblox Studio:** it runs on Kombucha, the Wine build Vinegar patches for Studio, and follows its newest stable release as well as Roblox's newest Studio. Microsoft's WebView2 runtime is installed in Studio's prefix, so Studio's own sign-in, Toolbox and Creator Hub pages work again; before, Studio stopped at "Launch Failed" when it tried to show its login. The new **Studio** section has the renderer (DXVK, DXVK-Sarek for older graphics cards, Wine's Direct3D through OpenGL, or Vulkan with Vinegar's layer for the swapchain errors Studio does not handle), the graphics card, GameMode, Discord presence for the place you are building, a backup of your sign-in and Studio's settings outside Wine's prefix, the system light/dark theme, Studio's own fast flags, an overlay folder, a Kombucha release or Wine of your own to use, and a Studio version or channel to stay on. If Roblox's main download server refuses a request, Studio's packages come from Roblox's alternate hosts. DXVK now sits next to Studio instead of in the prefix; an earlier install is moved over.
- **QuadraHQ/Quadra:** the repository moved from CiderHQ-org/Cider. The old addresses keep redirecting, and an update moves an existing install's remote to the new one. The launcher's package is now `quadra`, the shim `libQuadraShims.dylib` and its settings variables `QUADRA_*`; variables set by hand as `MACOBLOX_*` are still read.
- **Simplified Chinese:** a new language in Settings, translated by 2112992430 (pull request #40). Strings that are not translated yet stay English.
- **Discord:** the presence shows the current Quadra logo.

Validation: the launcher test suite passes (432 tests, with isolated settings as in CI), and so do the GTK interface tests. Studio was run headless through a fresh install, every renderer, the Vulkan layer on a real NVIDIA GPU, GameMode, the settings backup and its restore into a new prefix, and the update of an install made by 0.36.p1 (by the updater of that very version). Not confirmed: signing in to a Roblox account in Studio, Discord presence text (Studio reports its documents only after sign-in), private channels and the account's own channel; each needs an account, and is covered by tests built from Studio's own log format and Wine's credential code only.

Fully close and reopen Quadra after updating. Studio is not in the Flatpak. OpenGL remains the default for the game; VR requires OpenGL or Vulkan/Zink. Native packages include the matching Metal host and framework. Install `.pkg.tar.zst` on Arch derivatives, `.deb` on Ubuntu 24.04+/Debian 13+, or the binary `.rpm` on current Fedora. Darling/CiderDarling downloads remain separate. Source archives, build recipes and `SHA256SUMS` are attached.
